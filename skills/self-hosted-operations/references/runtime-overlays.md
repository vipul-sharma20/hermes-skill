# Temporary overlays over immutable application installs

Prefer documented supported configuration. Do not add a key without verifying its reader or combine an older runtime with arbitrary current-main modules. If an overlay is genuinely required, obtain approval for that temporary strategy and exact service boundary; no automatic parent/gateway restart.

1. Discover active install, interpreter, frontend assets and effective enforcement layers from docs/source without changing them.
2. Copy the minimum required exact-installed-version modules/assets into an approved writable overlay. Keep unmodified dependency resolution explicit and test actual module paths.
3. Code using __file__ may discover plugins, auth providers, skills and assets relative to relocated roots. Mirror/link only exact trusted installed resources; verify capabilities match stock before a public bind.
4. Patch all relevant client/API/RPC/media limits consistently. Do not reduce a broader ingress cap while claiming an increase. Verify resize/downstream limits separately.
5. With approval start an isolated alternate loopback instance without sharing mutable production state unsafely. Run syntax/import/frontend checks, health/auth discovery and real endpoint boundary tests: exact permitted bytes accepted, one byte above rejected. Use valid content and account for wire encoding.
6. Remove probe artifacts; review diff and exact process environment. Preserve the stock supervisor command and installed tree as rollback.
7. Switch only the separately supervised authorized component; never kill the parent process/gateway doing the task. Compare unrelated service identity/health.
8. Report active-now, persistent overlay files, supervisor-restart persistence and image-recreation durability separately. Manual background launch proves none of the latter automatically.

Version-sensitive Hermes symbols are deliberately not hardcoded here. Consult current official configuration and installed readers: https://hermes-agent.nousresearch.com/docs/user-guide/configuration . An old successful upload probe is not a test of today's release or portable package.
